# ShopWave Shipping FAQ

- Standard shipping: 3-5 business days. Express: 1-2 business days.
- Carriers used: UPS, FedEx, USPS, DHL. Tracking numbers are provided once an order ships.
- "Processing" means the order has not shipped yet; no tracking number exists.
- If a package shows delivered but the customer did not receive it, wait 24 hours, then the support agent should escalate to a human for a trace request.
- Address changes are only possible while an order is in "processing" status, and require a human agent.
